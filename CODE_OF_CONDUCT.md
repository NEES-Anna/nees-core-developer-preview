# Code of Conduct

## Our Commitment

Nainacore Emotional Tech is committed to maintaining a respectful, constructive, and safe developer preview environment.

This repository is for technical feedback, developer collaboration, and responsible discussion around AI governance infrastructure.

---

## Expected Behavior

Participants are expected to:

- Be respectful and constructive
- Share feedback in good faith
- Ask questions clearly
- Avoid harassment, abuse, or personal attacks
- Avoid sharing secrets, private credentials, or sensitive data
- Discuss AI safety and governance responsibly

---

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment or abusive language
- Spam or unrelated promotion
- Sharing private API keys or credentials
- Attempting to bypass access controls
- Posting harmful, illegal, or exploitative content
- Misrepresenting NEES Core Engine behavior or access

---

## Reporting

If you notice harmful or inappropriate behavior, please report it through the official Nainacore Emotional Tech contact channel.

Website: https://www.nainaaicreation.com

---

## Scope

This Code of Conduct applies to this GitHub repository, issues, pull requests, discussions, and related developer preview communication.
