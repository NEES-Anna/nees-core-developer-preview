# Code of Conduct

## Our Commitment

Nainacore Emotional Tech is committed to maintaining a respectful, constructive, and safe developer preview environment.

This repository is for technical feedback, developer collaboration, reproducible governance evaluation, and responsible discussion around AI governance infrastructure.

---

## Expected Behavior

Participants are expected to:

- Be respectful and constructive
- Share feedback in good faith
- Ask questions clearly
- Avoid harassment, abuse, or personal attacks
- Avoid sharing secrets, private credentials, or sensitive data
- Discuss AI safety and governance responsibly
- Distinguish reproducible technical findings from speculation or personal attacks
- Use the appropriate public or private reporting path for the type of finding

---

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment or abusive language
- Spam or unrelated promotion
- Sharing private API keys, credentials, access tokens, or sensitive data
- Attempting to access private infrastructure or systems beyond explicitly provided access
- Posting harmful, illegal, exploitative, or deliberately disruptive content
- Publishing sensitive exploit details that create immediate security risk
- Misrepresenting NEES Core Engine behavior, assurance status, access, or evidence

---

## Reporting

If you notice harmful, abusive, or inappropriate community behavior, contact Nainacore Emotional Tech privately:

**Email:** info@nees.cloud  
**Website:** https://nees.cloud

For security vulnerabilities, credential exposure, bypass techniques, sensitive infrastructure details, or other findings that could create immediate security risk, **do not open a public GitHub issue**. Follow [SECURITY.md](SECURITY.md) and report the issue privately to `info@nees.cloud`.

For a reproducible governance finding that can be safely disclosed publicly—such as a false allow, false restriction, missed ambiguity, wrong authority assessment, action/no-action failure, or inconsistent governance outcome—use the repository's **Governance Challenge** issue template.

For broader developer feedback, API/documentation feedback, or integration experience, use the appropriate GitHub template or the structured feedback form linked from the README.

---

## Scope

This Code of Conduct applies to this GitHub repository, issues, pull requests, discussions, and related NEES Core Engine V2 Developer Preview communication.

It does not grant permission to access private repositories, internal systems, private policies, production infrastructure, credentials, or any other non-public NEES or Nainacore resource.

---

## Enforcement

Nainacore Emotional Tech may remove content, close or lock discussions, restrict participation, or revoke Developer Preview access when necessary to protect participants, systems, credentials, private data, or the integrity of the evaluation process.

Actions will be based on the behavior and risk involved rather than disagreement with criticism. Good-faith technical criticism, reproducible governance challenges, and negative findings are welcome when shared responsibly.
