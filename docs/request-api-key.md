# Request a NEES Developer API Key

NEES Core Engine V2 is currently available through controlled Developer Preview access.

API keys are manually reviewed and issued to selected builders, developers, researchers, and product teams.

---

## Who Can Request Access?

You can request access if you are:

- building an AI product
- testing AI agents
- developing an AI assistant
- exploring AI governance
- working on customer-support automation
- building an education or productivity AI tool
- researching governed runtime behavior

---

## How to Request

Open a GitHub issue using the **API Key Request** template.

Please include:

1. Name
2. GitHub profile
3. Email or contact method
4. What you are building
5. How you plan to test NEES
6. Expected use case
7. Whether you are testing as an individual, startup, team, researcher, or student

If you do not want to publish an email address in a GitHub issue, contact:

```txt
info@nees.cloud
```

---

## Important Notes

- Do not share private credentials in public issues.
- API keys may be limited during Developer Preview.
- Access may be revoked for abuse, spam, unauthorized bypass attempts, or misuse.
- Never expose a real API key in client-side production code, screenshots, logs, source control, or feedback reports.
